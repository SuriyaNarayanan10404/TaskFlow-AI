# TaskFlow AI

TaskFlow AI is a mini productivity dashboard built using HTML, CSS, and JavaScript.

## Features
- Create Tasks
- Edit Tasks
- Delete Tasks
- Task Status Management
- Dynamic Dashboard Counters
- AI Productivity Suggestion
- Local Storage Support
- Responsive UI

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Project Type
Mini Full Stack Frontend Project
